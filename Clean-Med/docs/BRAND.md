# Clean Med

**Clear thinking. Visible connections.**

Clean Med is the identity of this independent educational health-tech project. The name appears in the application, navigation, export metadata, downloaded report names, source package, and project documentation.

## Visual direction

The interface combines a forest-green navigation rail, a soft sage introduction, white work surfaces, and restrained mint accents. The hierarchy puts readable evidence before decorative metrics. The connection illustration is an original SVG, delivered locally with the application.

| Role      | Light theme | Purpose                                     |
| --------- | ----------- | ------------------------------------------- |
| Forest    | `#132e2a`   | Navigation and brand presence               |
| Deep teal | `#103e3b`   | Brand symbol                                |
| Teal      | `#087c69`   | Links, selections, coverage                 |
| Mint      | `#b2f0ce`   | Symbol detail and contrast on dark surfaces |
| Sage      | `#eaf3eb`   | Introduction and breathing room             |
| Off-white | `#f4f7f6`   | Workspace background                        |

Typography uses the device’s native sans-serif stack, starting with Segoe UI. No third-party fonts or remote assets are requested.

## Brand assets

- [`assets/favicon.svg`](../assets/favicon.svg): compact symbol for app navigation and the browser tab.
- [`assets/logo.svg`](../assets/logo.svg): full Clean Med wordmark for light backgrounds.
- [`assets/connection-map.svg`](../assets/connection-map.svg): decorative evidence-to-explanation illustration.
- [`docs/images/`](images/): real desktop and mobile screenshots, regenerated with `npm run screenshots`.

Use **Clean Med**, with a space and capitals. Use `clean-med` in filenames, repository names, and storage keys. Keep the symbol proportional and leave enough space around it to read clearly.

The mark combines an open C with an offset plus. It represents the project’s identity; it does not signify accreditation, clinical validation, or a registered trademark.

## Voice

Use plain, direct language. Explain how results were reached. Describe scores as rule coverage. Distinguish a demonstration from medical advice without making the interface feel alarmist. Avoid invented testimonials, unverifiable accuracy claims, or implied medical credentials.
