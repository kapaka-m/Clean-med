# Clean Med — نظام خبير قابل للتفسير

مشروع تعليمي بيشرح إزاي الأنظمة الخبيرة بتربط الأعراض بقواعد محفوظة، مع عرض تفسير واضح لكل نتيجة. الواجهة بالإنجليزية .

![واجهة المشروع](images/clean-med-workspace.png)

## التشغيل

افتح `index.html` مباشرة في المتصفح.
أو شغّل المشروع بسيرفر محلي باستخدام Node.js إصدار 22 أو أحدث:

```sh
npm start
```

افتح `http://127.0.0.1:4173`.

## إمكانيات المشروع

- اختيار وبحث وتصفية 30 عرض من أربع مجموعات.
- مقارنة الأعراض بـ12 قاعدة لأمراض مختلفة، مع شرح النتيجة.
- توضيح الأعراض المتطابقة وغير المختارة والإضافية.
- التحقق من قاعدة مرض محدد.
- مكتبة معرفة قابلة للبحث وصفحة بتشرح طريقة الحساب.
- حالات تجريبية خيالية وتصدير تقرير JSON.
- واجهة متجاوبة للموبايل ووضع داكن واستخدام بالكيبورد.
- اختبارات للمنطق ولتجربة المتصفح وفحوص آلية لإمكانية الوصول.

**نسبة التطابق مش احتمال الإصابة.** لو قاعدة مرض فيها خمسة أعراض واخترت ثلاثة منهم، النتيجة 60% تغطية للقاعدة. البيانات تعليمية وغير معتمدة طبيًا، والمشروع مش أداة تشخيص.

